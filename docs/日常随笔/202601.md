劝孩子努力，别只讲"考好大学，找好工作"这样的大道理。孩子体会不到那么远，他们甚至觉得打工比读书轻松。

不如换成他们能听懂的话："你有没有发现，班里成绩靠前的学生，往往更自由？偶尔忘带作业，老师也愿意多提醒一句；小组讨论时，大家都自然听他的意见 -- 这不是偏爱，而是实力赢来的信任"



|                                          | 核心                                     | 应用                                             |
| ---------------------------------------- | ---------------------------------------- | ------------------------------------------------ |
| 家庭的第一性原理是经济，不是感情         | 没有经济基础的感情像空中楼阁             | 优先解决收入，房贷等现实问题，再谈"诗和远方"     |
| 职场的第一性原理是价值，不是努力         | 老板为结果买单，不为辛苦鼓掌             | 加班 != 升职，先思考"我的工作创造了什么实际收益" |
| 教育的第一性原理是培养能力，不是分数     | 社会考验的是解决问题的能力，不是试卷分数 | 让孩子学做饭比逼他刷题更能适应未来               |
| 健康的第一性原理是自律，不是医疗         | 治病是补救，防病才是根本                 | 每天早睡比囤保健品更有用                         |
| 创业的第一性原理是市场需求，不是个人喜好 | 你爱喝奶茶 != 全世界都需要奶茶店         | 先调研"别人需要什么"，再决定"我想做什么"         |
| 投资的第一性原理是风险控制，不是高回报   | 赚10次抵不过亏1次                        | 永远问自己："最坏情况我能承受吗？"               |
| 养老的第一性原理是提前规划，不是依赖子女 | 子女的压力可能比你还大                   | 30岁开始存养老金，比指望"养儿防老"更靠谱         |
| 成长的第一性原理是反思，不是经历         | 重复踩坑10年 != 有经验                   | 每天花5分钟复盘："今天哪些事可以改进"            |
| 爱情的第一性原理是筛选，不是死磕         | 不合适的人，磨合十年也很难幸福           | 婚前睁大眼，婚后少抱怨                           |
| 人际关系的第一性原理是互利，不是讨好     | 单方面付出迟早会失衡                     | 帮人是也大方提需求："下次我有困难找你哦！"       |
| 阅读的第一性原理是思考，不是浏览         | 读完100本书不思考，不如精读1本           | 合上书问自己："这本书改变了我的什么认知"         |
| 时间管理的第一性原理是优先级，不是计划表 | 时间无法被管理，但你可以管理任务的重要性 | 每天只做3件最重要的事，其他学会说不              |
| 沟通的第一性原理是理解，不是说服         | 对方感受到被听见，才会愿意听你说         | 先问"你为什么这么想"，再表达自己的观点           |
| 学习的第一性原理是实践，不是记忆         | 背100个公式不如动手解决1个问题           | 学完新知识立刻尝试教别人或写总结                 |
| 决策的第一性原理是目标，不是选项         | 选什么不重要，为什么选才重要             | 纠结时问自己："这个选择离我的终极目标更近吗"     |
